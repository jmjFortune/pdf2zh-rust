# 段落可靠性修复依据

当前 engine 在逐行拼接后全局删除 `- `，会改变原本位于行内的 `A- B` 和图注分隔符。保留行边界即可避免全局替换；普通行尾连字符保留，软连字符才移除。

普通文本的 fit_translation 和带公式文本的 typeset::fit 都发生在删除原文之前，可以对明确的溢出类型安全降级。remove_text 之后的失败必须终止，不能用 continue 掩盖。

translate_pair 当前逐段回退时用两个问号串联，后一段失败会丢失返回值中的前一段成功结果。引擎改用“尝试批量”的接口；批量不兼容时只翻译当前段，下一段回到原来的页循环。

UI 的任务映射原来忽略 Progress.message；需要将已有 message 加入展示文本，才能保留完成告警，无需改动前端视觉或状态机。
